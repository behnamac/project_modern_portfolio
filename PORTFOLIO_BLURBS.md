# Portfolio descriptions

## Short (one-liner)

A portfolio that boots instead of scrolls — a macOS desktop rebuilt in React, where each section of my CV is an app you open.

## Medium (card blurb)

DeskFolio is a macOS-inspired desktop environment built with React, Vite, Tailwind CSS 4 and Framer Motion. Instead of scrolling a landing page, visitors boot into a desktop with a live menu bar, a magnifying dock and draggable windows: projects live in Finder, the tech stack prints in Terminal, experience sits in Notes, testimonials in Photos. A Zustand store acts as the window manager (focus ordering, minimize, drag), and under 768px the whole thing swaps to a separate iOS-style home screen rather than a squashed desktop.

## Long (case-study intro)

I wanted a portfolio people would play with rather than skim, so I built one as an operating system. DeskFolio boots into a macOS-style desktop in the browser: a wallpaper, a menu bar with a live clock and theme switcher, double-clickable desktop icons, and an Aceternity-based dock retuned to real macOS magnification curves. Every window is genuinely draggable with correct z-index focus ordering, minimize and close — all driven by a single Zustand store that acts as the window manager. Each app is a real section of my CV: Finder holds projects, Terminal prints my stack line by line, Notes holds experience and education, Photos turns testimonials into a gradient grid, and Trash is a joke about the portfolio clichés this one avoids. All content lives in one constants file, and apps are registered through a single registry that the dock, window manager and mobile shell all read from — adding an app is one component plus one entry.
